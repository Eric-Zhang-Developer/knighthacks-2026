## What shipped
`POST /api/scorecard/:versionId` scores a saved idea version on the event's five criteria (Originality, Technical Understanding, Functionality, Design, Wow Factor), each on its own: a 1–5 score, points for and against, and a label; no total, no win chance. Points cite only the version's top-three evidence cards (generated if missing, as snapshots do). A recognized citation no longer promotes an inferred or unverified point to supported; criterion support now requires every point to be explicitly supported and grounded. Originality points without a neighbour are dropped; a criterion missing a point either way is `null` with "evidence is insufficient". Insert-only; `GET` returns the newest.
